# Imaikka Art Studio

Responsive React + TypeScript + Vite website built from the supplied Imaikka Art Studio design references.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The site includes Home, Our Story, Artworks, Custom Creations, Art Academy, Events, and Contact pages. Enquiry forms currently show demo feedback and do not deliver messages; connect an email service before using them for live enquiries.
